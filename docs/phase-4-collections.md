# 第7步：收藏、书写模板、图文微光与私人瓶子

## 功能

- 所有记录可收藏/取消收藏；“我的记录”新增全部、收藏、整理卡、微光、瓶子筛选。选筛选时清空日期/搜索限制，避免收藏被旧日期条件隐藏。
- 整理卡继续使用原四步整理界面重新编辑；旧草稿保存时保留正式记录的当前收藏与瓶子标记，避免过期草稿覆盖新操作。
- 五套模板为：今天的心情、睡前放一放、给自己的一封信、今天的一点微光、我的小小勇敢。每套包含两个问题，使用统一编辑器，可删除问题、自由改写、添加照片。微光模板保存为joy类型。
- 放松页与记录页可新建自定义微光；支持可选标题（最多60字）、文字、情绪和最多3张照片。纯标题也可保存；编辑器保留joy/bottle类型。
- 正式记录保存后可选择“留在这里”或“装进瓶子”。记录列表也能打开放漂仪式。放漂只增加原记录的bottled标记，不复制正文或图片、不新增记录，也不向外发送。
- 原心事页独立瓶子输入/收藏界面移除，改为统一编辑器与统一记录筛选；旧bottle类型记录无需二次转换，仍可查看、编辑、删除。
- 预设微光打卡与自定义微光区分处理：同名自定义微光不会成为预设打卡取消操作的目标。
- 瓶子标记动画与保存反馈保留；操作失败仍保留原正式记录。

## 数据

schemaVersion仍为1；新增可选bottled布尔字段，缺少该字段的旧数据正常读取。timeline现在返回全部类型，避免将微光和旧瓶子排除在统一记录之外。

收藏与瓶子状态通过repository更新有效文档；失败沿用原回滚机制。重复装瓶幂等；原记录编辑后瓶子自动显示更新内容；删除原记录即从所有筛选中移除，没有另一份副本。

内部故障恢复副本仍按既有规则保留；“删除全部数据”及用户备份管理属于第10步。
