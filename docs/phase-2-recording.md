# 第4步：快速记录、图文编辑和自动草稿

## 实现内容

- 此刻页：原有五个快捷心情选项下增加“只记下心情”和“多种感受 / 写一点”。快捷保存不要求文字，保存成功后清空选中，防止重复点击。
- 新增独立RecordEditor：11种情绪最多选3种；可选0—10强度；7个预设生活标签与自定义标签（每个最多20字、总计最多12个）；文字最多5000字；最多3张照片。
- 纯心情、纯文字、纯照片均可保存；只有标签或强度不构成一条记录。正式保存保留稳定id、创建日期、照片、收藏及既有整理结果。
- 我的记录：同时显示快捷心情和手记，展示多情绪、强度、标签和照片；支持标签搜索；统一按完整id编辑、删除。旧记录兼容。
- 自动草稿：打开编辑器和每次内容变化后排队写入；“稍后继续”等待落盘后关闭；“舍弃草稿”需用户确认，不修改原正式记录。再次进入时提示继续草稿或舍弃后打开新内容。
- 保存成功后清理草稿；若草稿清理失败，提示正式记录已经保存。重存同一草稿按id更新，不重复新增。
- 返回键在编辑器内提示通过“稍后继续”离开，防止无意退出；练习和插画空间可直接返回。

## 数据与照片

- 正式数据仍使用 `zhiyu_journal`，schemaVersion保持1（沿用第3步预留字段）。
- 草稿使用独立Preferences文件 `zhiyu_editor_drafts`，键 `editor_draft_v1`，使用版本化单记录文档。分开文件防止草稿flush影响正式记录事务。
- 系统PhotoViewPicker只选择照片，最多剩余数量，不请求全相册读取权限。
- 图片通过文件描述符复制至应用 `filesDir/photos/`，记录保存相对路径，原相册照片不修改。
- 每张限制30MB；选择取消不产生文件；复制失败时关闭源句柄并移除本次部分导入文件。
- 启动时清理未引用的自有图片：保留正式文档、上一版恢复文档和草稿引用。任何引用文档读取异常时不清理。保守保留恢复副本中的照片；第10步删除全部数据须覆盖所有副本。
- 图片暂不做压缩、裁剪和全屏查看。草稿写入是异步落盘；突然断电或强杀发生在flush完成前，最后一次变更仍可能未持久化。界面以“草稿已保存在本机”表示成功，不在失败时给出成功反馈。
