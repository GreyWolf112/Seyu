# 第8步：环境音、睡前放松、呼吸练习

## 已实现

- 放松页的安静空间提供雨声、海浪、林间风三种离线自然录音循环音。默认不播放，音量初始35%，支持静音及5/15/30分钟定时关闭（默认15分钟）。修改定时时长从修改时重新计时。
- 音轨切换先释放上一播放器和文件描述符；离开空间、切到后台、系统音频中断均停止，不自动恢复。暂不支持锁屏后台持续播放。
- 睡前流程：安顿身体 → 暂放心事 → 留下明天的一小步 → 晚安。支持上一步、跳过、退出，完成后可主动进入环境音空间。无强制记录、打卡或睡眠效果承诺。
- 呼吸练习支持1/3分钟，4秒吸气、6秒呼气提示，不屏息。支持暂停、续练、重新练习；暂停时切换时长会重置。后台自动暂停。时间按实际经过毫秒计算，避免定时回调延迟导致累计误差。
- 呼吸与安静空间内容可滚动，避免小屏高度不足时操作按钮不可达。

## 音频来源

旧版合成噪声已在用户反馈后替换为CC0自然录音。海浪使用岩石海岸实录，林间声使用风吹树叶和鸟鸣场景。每段60秒、44100Hz、单声道16位PCM，合计约15.1MiB。来源、许可和复现方法见 [ambient-audio-sources.md](ambient-audio-sources.md)。

- WAV检查覆盖格式、时长、非静音和无削波；呼吸测试覆盖延迟回调、暂停续练、完成重启、时长重置。
