# 第9步：情绪回顾

## 入口和体验

“我的记录”顶部的静态总数卡替换为近7天／30天回顾，日期范围含今天，按设备本地日历计算。

- 默认显示记录天数、记录条数及生活微光条数，细节按需展开。
- 展开后显示情绪、场景标签各自出现的天数，最多展示前4项；同一天同一项重复记录只计一天。
- 日格标出记录条数，没有记录显示“—”，不推断情绪。
- 点击有记录的日期会收起回顾、清空搜索与分类筛选、切到当天的全部记录，并在布局更新后定位到记录区。
- 回顾与下方搜索、收藏等筛选独立，以所有已保存记录为基础；编辑、保存和删除会更新回顾。进入页面或应用回到前台时重新确定日期范围。
- 没有数据或带情绪的记录不足3天时给出温和说明，不催促打卡或声称发现规律。

## 统计边界

所有正式记录类型参与统计，草稿不参与。按记录所属日期而非最后编辑时间计算，旧记录不会因为今天编辑而被算作今天。

同一记录可以带多种情绪，情绪天数不互斥；不计算正负评分、连续打卡、诊断或情绪强度的健康含义。生活场景来自用户填写的标签，不分析正文，也不推断因果。微光数量仅为joy类型记录数，不代表快乐程度。

日期统一兼容 `2026-10-09` 与 `2026-10-9`。日期过滤和日历标记同步使用归一化日期，避免回顾有记录而打开当天列表却遗漏。

## 实现

- `models/MoodReview.ets`：纯函数生成回顾和逐日标签集合，无存储或网络请求。
- `models/RecordDate.ets`：本地日期归一化及无效日期拒绝。
- `components/MoodReviewCard.ets`：范围切换、空状态、展开统计与日格。
- `pages/JournalPage.ets`：接入回顾及当天列表定位。
- 原数据版本、音源和音频播放流程保持不变。
